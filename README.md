# LAM — Loving All of Me

Official source repository for the LAM premium African wellness website. The website uses the existing Lovable project's TanStack Start + TypeScript stack. Source updates will be built through GitHub. Connect this repository to the existing Lovable project to synchronize previews.

Launch phase: editorial homepage, curated product collection, wellness enquiry, Her, Uninterrupted RSVP interest and corporate hospitality enquiry. Payments, actual bookings and database subscriptions are not yet live.
