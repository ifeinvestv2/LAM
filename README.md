# LAM — Loving All of Me

Luxury African wellness and lifestyle landing page, developed directly via GitHub without Lovable chat-credit usage.

## What has been built

- Responsive home page: brand positioning, product catalogue, wellness, Her Uninterrupted January 2027 dinner series, corporate hospitality, planned Wellness House, LAM Circle.
- Real WhatsApp links for product orders, events, and wellness enquiries.
- Mobile navigation, metadata, typography, palette, accessibility and reduced-motion support.
- GitHub Actions workflow verifying TypeScript and production build on every push to main.

## Important: connect to Lovable

**Lovable's native Git sync cannot attach a project to an existing GitHub repository.** Connecting the existing Lovable project from Project settings → Git → GitHub creates a **new** GitHub repository under the selected account. Once this is done, the website code in `ifeinvestv2/LAM` needs to be copied/merged into the newly-created synced repository on its active branch. Do not delete the new repository or assume edits to this repository appear in the Lovable preview before that transfer.

Project: https://lovable.dev/projects/ed9ecbab-c625-40ed-9942-347204db185d

## Technology

TanStack Start, React, TypeScript, Tailwind CSS and Lucide icons. Match the Lovable project's starter stack. CI uses Bun.

## Launch limitations

- Editorial stock imagery is temporary; replace it with the real LAM branded product and event imagery before launch.
- Product availability and prices should be confirmed; page links currently open WhatsApp enquiries rather than checkout.
- The LAM Circle form opens a prepared WhatsApp registration message; it does not yet store emails in a database.
- The Wellness House is a future concept, not a currently operational venue.
- Final privacy policy, approved contact details, product dietary declarations, imagery rights and live booking/payment providers remain launch tasks.
